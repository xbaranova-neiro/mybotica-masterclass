# MyBotica · 7 ноября 2026

Живой онлайн-практикум с Ксенией Барановой. Начало — 12:00 МСК.

Самостоятельная статическая страница для маршрута `/web7nov/`. Откройте `index.html` или запустите любой статический HTTP-сервер из корня репозитория. Сборка и зависимости не нужны.

Изображения, логотип и шрифты находятся внутри `assets/`; страница не зависит от соседних папок.

Кнопки открывают GetCourse-форму поверх страницы. После успешной регистрации посетитель переходит на страницу «Спасибо» со ссылкой на бота; бот направляет в канал, где выдаются оба урока. Отправка контрольной заявки и получение подарков пока не проверялись.

Подвал перенесён из предыдущего мастер-класса MyBotica: реквизиты компании и школы, лицензия школы, ссылки на документы.

## Быстрая загрузка

Все иллюстрации доставляются в WebP с прозрачностью, в вариантах 480/900/1400 px. Браузер выбирает размер через srcset; изображения ниже первого экрана загружаются отложенно. Главная иллюстрация имеет высокий приоритет. Размеры заданы заранее, чтобы страница не прыгала при загрузке.

Используются два локальных файла Manrope WOFF2 общим весом 39 КБ с предзагрузкой и font-display:swap. Шрифты не загружаются с чужих сервисов. Скрипт GetCourse и iframe формы загружаются только после нажатия кнопки регистрации.

Изображения имеют имена с хешем содержимого; CSS и JS получают версию в URL для обновлений без сброса кэша всех иллюстраций. Заголовки длительного серверного кэширования зависят от конфигурации хостинга.

Актуальный статический вес — в PERFORMANCE.json; вес внешнего виджета в него не входит. Это не замер времени загрузки по сети.

## Кнопки регистрации

Все 11 элементов записи и получения подарков используют атрибут `data-register` и единый обработчик. Переходы к нижнему блоку или урокам не используются; ссылки программы и возврата наверх остаются навигацией.

Подключён GetCourse-виджет 1675822. Форма загружается при первом открытии, получает параметры URL, включая UTM, и сохраняется при повторном открытии. Событие `mybotica:registration` доступно для аналитики; `event.detail.source` содержит место нажатия.

Проверены открытие из программы, подарка и финального блока; закрытие кнопкой и Escape; сохранение позиции при повторном открытии.

## Кто будет с участниками

Общий блок Ксении Барановой и Карины Комяк: Ксения ведёт эфир, Карина делится материалами и помогает до эфира. Совместная иллюстрация с дракошей заменяет одиночный портрет ведущей; в публикации только адаптивные WebP, без исходных фотографий.

Registration: every data-register button opens the shared native dialog. GetCourse widget 1675822 loads on first click, retains one iframe across reopenings and receives page query parameters. Provider success message is accepted only from the embedded iframe at https://neyroseti.neiroguru.ru; it redirects the top-level page to https://xeniabaranova-school.ru/sps/neyroseti/thank_mbnov26. Small screens fit the provider's minimum form width. No test registration or consent submission was performed.

Маршрут получения подарков: регистрация → бот → канал → два видеоурока. Бот выдаёт ссылку на канал; сами уроки размещаются в канале.
